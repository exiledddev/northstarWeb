# Security

Please **do not open a public issue** for a security problem in Blackline Web
— sign-in, sessions, or who may read or write which script.

Report it privately through GitHub: the repository's **Security** tab →
**Report a vulnerability**, or email **hello@nativecompute.com** with
"Blackline security" in the subject. The full policy is in the main
repository's [SECURITY.md](https://github.com/exiledddev/northstar/blob/main/SECURITY.md).
